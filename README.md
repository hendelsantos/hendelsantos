I'm a software developer, entrepreneur, and technology enthusiast passionate about building solutions that solve real problems.

My professional background combines **software engineering, requirements analysis, industrial processes, business operations, automation, and data analytics**.

I work across different technologies because I believe the most important engineering decision comes before choosing a programming language.

My core focus areas:

- 🤖 **AI-Augmented Engineering:** Using AI coding agents to accelerate software delivery while maintaining engineering discipline.
- 🧩 **Requirements & Architecture:** Translating business needs into structured requirements, architecture, and maintainable software.
- 🏭 **Industrial Technology:** Applying software and data analysis to production, maintenance, inventory, costs, and operational processes.
